### Objective

A field voice note enters as evidence on Android exactly like every other captured asset: microphone recording into the OFFLINE-FIRST capture session (the journal is the local truth; recovery re-opens interrupted sessions exactly once), honest device-measured voice metadata in the asset's `AcquisitionMetadata` — where Android is STRONGER than the web lane it says so, and where the device cannot measure it says nothing — registration over the UNCHANGED 1.1.0 `Evidence` document riding the SAME manifest → `CaptureSessionEnvelope` → `POST /v1/capture/assets/:contentId` + `POST /v1/capture/sync` path every Android asset already uses, and the transcript state CLIENT-ONLY: with no ASR provider configured the voice note syncs like any asset and its derivations set is honestly empty — never an error, never a fabricated transcript.

- Honest voice metadata on Android — per the contract header (`packages/shared-contracts/src/evidence.ts`) and the fixture `packages/shared-contracts/fixtures/evidence/Evidence.valid-voice-note.json` (all values strings; numeric values string-encoded integers). The four canonical keys join `AcquisitionMetadataKeys` in `apps/android/core/src/main/kotlin/org/payswap/aise/core/capture/AcquisitionMetadata.kt` (the VOICE-001 §5.4 hand-off) and ride the asset's `AcquisitionMetadata` verbatim, preserved into the manifest by `SessionManifestExporter`:
  - `voice.codec` — the device's ACTUAL encoder, STRONGER than the web lane's claim (the web lane reports the browser-observed container subtype; the Android recorder configures its encoder explicitly). This is the contract's own "device that knows its encoder" case — the fixture's `opus` exemplifies it. The value is what the recorder was configured to produce (`aac` for AAC in an `audio/mp4` container, `amr-nb`, `opus`, … from the MediaRecorder/MediaCodec profile the adapter sets), never a guess behind a container, never invented when the configuration is unknown.
  - `voice.duration.ms` — measured when measurable (MediaExtractor/MediaMetadataRetriever over the committed file after the recorder closes it); honestly absent when the platform cannot measure it.
  - `voice.sample.rate.hz` — from the extractor/codec format when measurable (string-encoded integer, e.g. `48000`); honestly absent when not.
  - `voice.language.hint` — an OPTIONAL user-entered advisory (a hint for ASR providers and UIs, never an authoritative language determination); absent by default.
  - The lane sets the well-known `capture.kind` to `"voice"` (the operator chose the voice entry — a fact, not an inference), and may carry `acquisition.sensorId` (e.g. the audio source the adapter used).
