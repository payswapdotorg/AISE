# ANCHOR-007 — The Fixture (per-item provenance)

One REAL documented site, one REAL line-art measured drawing, sixteen REAL
photographs, six DERIVED-DRILL instrument-validation stills. Fidelity
classes are declared per item and never upgraded.

## The site and the plan (REAL)

**Site:** Edith Farnsworth House (Mies van der Rohe, 1945–51), 14520
River Road, Plano, Kendall County, Illinois — **HABS IL-323**.

**The plan raster** (`fixture/plan-raster.png`, 3401×2307, derived from
`plan-source.jpg`, the pinned Wikimedia Commons 3840×2560 rendition of
HABS IL-323 **sheet 3 of 8** — the line-art measured drawing carrying BOTH
level plans, public domain, US government work):

- `rasterToScene.pixelsPerMeter = 88.00` — re-measured by
  `tools/measure_plan_geometry.py` against the sheet's **METERS graphic
  scale bar** (0-tick..3-m tick); cross-checked twice independently:
  the FEET bar (267 px / 10 ft = 87.60 px/m, −0.45%) and the printed
  scale 1:48 of a 36×24 in sheet scanned at 200 dpi with the rendition
  factor 8/15 (87.47 px/m, −0.6%).
- `rasterToScene.xDirection = "east-right"`, `yDirection = "north-up"` —
  the crop was rotated by the re-measured **north-arrow needle medial
  axis** (10.0314° counter-clockwise, subpixel fit over 29 rows,
  residual RMS 0.09 px) so true north is UP: THE HANDEDNESS LAW is true
  by construction.
- `worldOriginPx = [1700.5, 1153.5]` — the crop center; a declared local
  plan frame (x east, y north).
- `ground-truth-plan.json` — the measured-drawings corner coordinates of
  the pavilion slab, glass envelope, service core and lower terrace in
  raster px (the realized-error instrument's reference points).

## The drills (DERIVED-DRILL — never presented as real)

`drill-path-a1..a3.png`, `drill-path-b1..b3.png` — true pinhole renders of
the plan raster's line-work on the ground plane z=0 (plus vertical members
to 1.6 m at ~2.2 m spacing where the plan carries ink), degraded (blur +
noise, fixed seeds), each with its KNOWN plan->drill homography recorded in
`fixture/drill-ground-truth.json` (`knownHomographyPlanToDrill`, the exact
ground-plane projection). Camera parameters per drill are declared in the
per-drill `derivation` string. These are instrument-validation artifacts:
they exist to measure whether each lane's instrument recovers a KNOWN
transform on clean inputs before the lanes are measured against real
photographs — nothing else. The photoset's REAL fidelity class is never
upgraded by them.

## Digests and integrity

Every fixture file is content-addressed: the manifest carries the
sourced-rendition digests, the harnesses compute and check the committed
file digests against the manifest before every run (drift = hard error),
and the plan raster's digest is cross-checked in the request builder. The
drills' digests are listed in `drill-ground-truth.json`. The supervised
runner's input-digest audit covers every request byte on every run.
