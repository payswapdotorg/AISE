## The sandbox

`apps/spatial-studio-spike/` — a browser sandbox rendering the pinned GBIM-000 canonical fixture in
3D (Three.js 0.186.1) and 2D plan (deterministic SVG), with selection, sectioning, measurement,
object inspection and synchronized view state, prototyping the Atelier-inspired interaction
patterns as a PURE PRESENTATION ADAPTER over the canonical AISE solution engine (every quantity,
validation and identity displayed is an engine output rendered verbatim; the renderer holds no
authority). See `adapter-notes.md` for the architecture and `sandbox-host/` for host mounting.

## Reproduce (in a fresh clone at base + this branch)

```bash
bun install
bun apps/spatial-studio-spike/src/server/run-checks.ts   # writes results/spike-results.json (16 checks)
```

The browser sandbox additionally requires a bundler host — see `sandbox-host/MOUNT.md` (the
delivered sandbox host is a Next.js app that maps `@spike/*` and `@aise/*` through tsconfig
paths; `bun install three @types/three web-ifc` in the host provides the renderer externals).
