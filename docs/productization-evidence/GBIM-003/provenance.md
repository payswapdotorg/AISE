## Determinism

- `buildWorkspaceRecord()` is pure: two independent builds produce byte-identical
  `WorkspaceDto` projections (check `fixture-replay-determinism`).
- The check runner is deterministic (fixed instants, no network, no clock, no randomness) and
  writes `results/spike-results.json` — rerunning reproduces identical content.
- The agent trace is generated through the REAL deterministic compiler with an injected fixed
  clock (`createSolutionCommandCompiler({ clock: () => "2026-09-25T00:00:00.000Z" })`); the
  compiled intent and its derived operation id are recorded in `results/agent-trace.json`.
- Operation/state identities are sha-256 content addresses (identity.ts) — stable for identical
  semantics + version context, forever.
